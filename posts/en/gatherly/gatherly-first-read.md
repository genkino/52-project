As the number of blogs you follow grows, checking each site for new posts can become a chore. You may also miss a new post from a site you visit only now and then.

Gatherly is an RSS reader that brings blogs and news feeds together in one place. You can start a subscription by entering the address of a Naver Blog, Tistory, Brunch, or velog site, or by adding an RSS feed URL. If you enter a regular website address to find a feed, check that the blog name and posts in the preview look right before you subscribe.

## Start with one subscription

1. Find the address of a blog you want to keep reading, or the public RSS feed URL provided by its publisher.
2. Enter the address in Gatherly and check the preview to make sure it shows the right feed.
3. Subscribe, then choose a post from the list to read.

If you already have a list of subscriptions, you can import it as an OPML file. As you add more sources, you can sort feeds with tags and save posts to read later.

Feeds work differently from site to site. Some include full articles, while others show only excerpts. If a site has no feed, or the preview does not look as expected, open the original webpage to read it.

If you want to change how you keep up with the blogs you enjoy, try adding one you read often. Find out more on the [Gatherly App Store page](https://apps.apple.com/app/id6756641122).
